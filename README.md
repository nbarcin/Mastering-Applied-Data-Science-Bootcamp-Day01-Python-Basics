# Mastering-Applied-Data-Science-Bootcamp-Day01-Python-Basics
## Day 01 – Python Fundamentals & Data Handling

**Mastering Applied Data Science Bootcamp**

## Project Overview

This project focuses on Python fundamentals, data manipulation, data exploration, visualization, and text-to-speech functionality. It demonstrates practical techniques for working with different data formats and performing basic data cleaning and analysis using Python libraries.

## Topics Covered

* **Python Fundamentals:** Variables, naming conventions, data types (`int`, `float`, `str`, `bool`, `list`, `dict`), operators, conditional statements, loops, and list comprehensions.
* **Data Import & File Handling:** Loading CSV, Excel, JSON, and HTML table data using Pandas.
* **Data Exploration:** Inspecting datasets with `.head()`, `.tail()`, `.shape`, `.describe()`, `.info()`, and `.isnull().sum()`.
* **Data Cleaning:** Handling missing values with `.fillna()` and removing unnecessary columns.
* **Data Visualization:** Exploring relationships between variables using Seaborn's `pairplot()`.
* **Text-to-Speech:** Converting text into speech using `gTTS` and playing audio with IPython's `Audio` module.

## Technologies & Libraries

Python · Pandas · Seaborn · gTTS · IPython · Jupyter Notebook

## Learning Outcomes

Gained hands-on experience with Python programming, data ingestion, exploratory data analysis (EDA), basic data cleaning, visualization, and text-to-speech processing.

All project code and outputs are available in this repository.
